
# UIC Career Fair Event Hub

An interactive, responsive career fair website developed as part of CodePath's WEB101 Web Development program. The website provides students with a centralized platform to explore career fair information and interact with an RSVP registration experience.

## Live Demo

[Visit the Website](https://saudb-codes.github.io/uic-career-fair-event-hub/)

## Features

- Responsive and user-friendly interface
- Light and dark mode toggle
- Interactive RSVP registration form
- Real-time RSVP counter
- Client-side form validation
- Animated RSVP confirmation modal
- Scroll-based animations
- Career fair information and navigation

## Technologies Used

- HTML5 - Website structure
- CSS3 - Styling, responsive design, and animations
- JavaScript - DOM manipulation, event handling, and interactive functionality
- GitHub Pages - Website hosting and deployment
- VS Code for Education - Development environment
