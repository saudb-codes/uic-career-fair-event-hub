# UIC Career Fair Event Hub

## Project Overview

An interactive, responsive career fair website developed as part of CodePath's WEB101 Web Development program. The website provides students with a centralized platform to explore career fair information and interact with an RSVP registration experience.

The goal of this project was to apply web development concepts while creating a user-friendly and interactive website for university students.

## Live Demo

[Visit the Website](https://saudb-codes.github.io/uic-career-fair-event-hub/)

## Features

- Responsive and user-friendly interface
- Light and dark mode toggle
- Interactive RSVP registration form
- Real-time RSVP counter
- Client-side form validation
- Animated RSVP confirmation modal
- Scroll-based animations
- Career fair information and navigation

## Technologies Used

- **HTML5:** Website structure and content
- **CSS3:** Styling, responsive design, and animations
- **JavaScript:** DOM manipulation, event handling, and interactive functionality
- **GitHub Pages:** Website hosting and deployment
- **VS Code for Education:** Development environment

## Development Process

I started by creating the basic website structure using HTML and styling the different sections using CSS. I then used JavaScript to implement interactive features such as the dark mode toggle, RSVP registration form, and real-time RSVP counter.

As the project progressed, I added form validation, scroll-based animations, and an animated confirmation modal to improve the user experience. Finally, I deployed the website using GitHub Pages.

## Challenges and Solutions

One challenge was implementing the RSVP form validation to prevent incomplete or invalid submissions. I used JavaScript to validate user input before updating the RSVP list and counter.

Another challenge was implementing an animated confirmation modal that appears after a successful registration. This involved combining JavaScript event handling with CSS animations to provide visual feedback to users.
